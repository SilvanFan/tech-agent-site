NIST徵求超級智慧系統效益評估實務草案意見

Towards Best Practices for Evaluating SI-Driven Uplift

NIST CAISSI 徵求 NIST SP 2400-801 評估實務草案的公開意見。

NIST 指出，效益評估是以證據支持超級智慧系統部署、採用與整合決策的重要依據。

為何入選

這是推論：若評估方法更透明且可重現，將有助於組織判斷超級智慧系統在實際情境中的效益與部署風險。

NIST is seeking input on draft practices for evaluating the real-world impact of superintelligence systems.

證據與限制

僅依 NIST 網頁摘要整理；文件仍是草案，所提供內容未詳述具體評估程序。

TACT-Bench 評估工具使用代理能否兼顧拒絕越權與完成正當任務

TACT-Bench: Testing Adaptive Conversational Threats against Tool-Use Agents

TACT-Bench 為對抗任務配置至少一個良性對照，並保留可合規完成的正當行動。

作者表示，TACT-Base 在其評測中使攻擊誘發失敗率較四種相容基準高 17.53%。

為何入選

這是推論：同時檢驗安全拒絕與正當任務完成，有助於發現代理人過度拒絕或遭操弄的風險，補足只測拒絕能力的評估盲點。

TACT-Bench tests whether tool-using agents can resist unauthorized requests while still completing legitimate tasks.

證據與限制

這是預印本，摘要僅提供基準設計與部分結果，未呈現完整實驗細節；數字是作者報告的評測結果，尚非獨立驗證。
